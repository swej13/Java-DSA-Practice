## 📌 About

**Java DSA Practice** is a collection of Data Structures and Algorithms programs implemented using Java.

The repository focuses on understanding the **logic, implementation, and working principles** of fundamental DSA concepts through practical programs.

---

## 🧠 Topics Covered

### 🥞 Stack
- Stack implementation using Array
- Push, Pop and Peek operations
- Stack-based problem solving
- String reversal using Stack
- Number reversal using Stack
- Palindrome checking using Stack

### 🔄 Expression Conversion & Evaluation
- Infix to Postfix conversion
- Prefix expression evaluation

### 🔤 Basic Problem Solving
- String reversal
- Number reversal
- Palindrome problems
